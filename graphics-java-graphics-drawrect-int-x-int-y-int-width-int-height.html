Java Tutorial - Java Graphics.drawRect(int x, int y, int width, int height)

Syntax

Graphics.drawRect(int x, int y, int width, int height) has the following syntax.

Example.java
publicvoid drawRect(int x,  int y,  int width,  int height)

Example

In the following code shows how to use Graphics.drawRect(int x, int y, int width, int height) method.

Example.java
import java.awt.Color;
import java.awt.Graphics;
import javax.swing.JFrame;
import javax.swing.JPanel;
publicclass Main extends JPanel {
  publicvoid paint(Graphics g) {
    g.setColor (Color.red);
    g.drawRect (0,0,100,100);
    g.clipRect (25, 25, 50, 50);
    g.drawLine (0,100,100,0);
  }
  publicstaticvoid main(String[] args) {
    JFrame frame = new JFrame();
    frame.add(new Main());
    frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
    frame.setBounds(20,20, 500,500);
    frame.setVisible(true);
  }
}
