Match a particular character a specified number of times.

There are two general ways the repetition operators work. One class of operators is greedy, that is, they match as much as they can, until the end. The other class is reluctant (or lazy), and matches only to the first chance they can terminate. For example, the regular expression .; matches any number of characters up to the last semicolon it finds. To only match up to the first semicolon, the reluctant version .?; must be used.
