Introduction

The following loop initializes the array array with user input values.

Example.java
import java.util.Arrays;

publicclass Main {
  publicstaticvoid main(String[] args) {
    int[] array = newint[5];

    java.util.Scanner input = new java.util.Scanner(System.in);
    System.out.print("Enter " + array.length + " values: ");
    for (int i = 0; i < array.length; i++)
      array[i] = input.nextInt();//www.java2s.comSystem.out.println(Arrays.toString(array));

  }
}
