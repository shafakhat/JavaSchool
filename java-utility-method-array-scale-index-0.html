double[]minMaxScale(final double[] x) min Max Scale

Example.java
DoubleSummaryStatistics s = Arrays.stream(x).summaryStatistics();

        : Arrays.stream(x).map(d -> (d - s.getMin()) / (s.getMax() - s.getMin())).toArray();
