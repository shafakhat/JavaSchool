## Question

Which type of loop has three segments within parentheses?

- A. do-while loop
- B. for (traditional)
- C. for-each
- D. while

```java title=Example.java
B.
```

## Note

A traditional for loop is best known for having an initialization statement, condition statement, and update statement.
