## Question

Select the valid primitive data types. (Select all that apply.)

- A. boolean
- B. bit
- C. char
- D. float
- E. All of the above

```java title=Example.java
A, C, D.
```

## Note

The second option is incorrect because there is no primitive named "bit"; there is a primitive named byte.
