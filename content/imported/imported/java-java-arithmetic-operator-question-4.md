## Question

What is the output of the following code?

```java title=Example.java
System.out.println("25 / 4 is " + 25 / 4);
System.out.println("25 / 4.0 is " + 25 / 4.0);
System.out.println("3 * 2 / 4 is " + 3 * 2 / 4);
System.out.println("3.0 * 2 / 4 is " + 3.0 * 2 / 4);
```

```java title=Example.java
25 / 4.0 is 6.25
3 * 2 / 4 is 1

```
