## Question

What is the result of the expression 5.4 + "3.2"?

- A. The double value 8.6.
- B. The String "8.6".
- C. The long value 8.
- D. The String "5.43.2".

```java title=Example.java
D.
```

## Note

The floating point value is converted to a String and is then appended to "3.2".
