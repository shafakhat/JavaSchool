Suggested study paths

  1. Fresh graduate path: Core tutorial → topic banks in sidebar order → Test 1 → master list skim → Tests 2-3.
  2. Working dev, 2 weeks: master list (skip what you know) → deep-dive Collections/Threads banks → Tests 2-3 timed → Advanced Java reading.
  3. Legacy stack (Struts/Spring/EJB): Web bank → Struts · Spring · EJB pages → archive examples in the sidebar.
