Using the break Statement in a Loop

Example.java
public class MainClass {
  public static void main(String[] args) {
    int count = 50;
    for (int j = 1; j < count; j++) {
      if (count % j == 0) {
        System.out.println("Breaking!!");
        break;
      }
    }
  }
}
