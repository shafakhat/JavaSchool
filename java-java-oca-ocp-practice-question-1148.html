Java OCA OCP Practice Question 1148

Question

An abstract class can contain methods with declared bodies.

  • A. True
  • B. False
Example.java
A.

Note

Abstract classes can contain methods that are defined and methods that are not defined.

Abstract classes can have abstract methods and non-abstract methods.
