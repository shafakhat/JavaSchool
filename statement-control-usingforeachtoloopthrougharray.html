Using 'for each' to loop through array

Example.java
public class MainClass {
  public static void main(String[] arg) {
    char[] vowels = { 'a', 'e', 'i', 'o', 'u'};
    for(char ch: vowels){
      System.out.println(ch);
    }
  }
}
