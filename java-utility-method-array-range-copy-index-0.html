boolean[]copyOf(boolean[] array, int length) Returns a copy of the given array of size 1 greater than the argument.

Example.java
boolean[] anew = newboolean[length];
for (int i = 0; i < length; i++) {
    if (i < array.length) {
        anew[i] = array[i];
        continue;
    anew[i] = false;
return anew;
