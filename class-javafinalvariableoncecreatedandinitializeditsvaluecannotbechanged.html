Java Final variable

Java Final variable: Once created and initialized, its value can not be changed

Example.java
public class Main {
  public static void main(String[] args) {
    final int hoursInDay = 24;
    System.out.println("Hours in a day = " + hoursInDay );
  }
}
//Hours in a day = 24
