booleanallEqual(int[] arr) Returns true if all values in the array are equal.

    if (arr[0] != arr[i])
        return false;
return true;

booleanallEquals(double[][] sims) all Equals

Example.java
double prev = 0;
for (int i = 0; i < sims.length; i++) {
    for (int j = 0; j < sims[0].length; j++) {
        if (!(i == 0 && j == 0))
            if (sims[i][j] != prev)
                return false;
        prev = sims[i][j];
return true;

        return false;
return true;
