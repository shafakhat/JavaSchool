double[][]array1DTo2D(double[] In, int H) Returns 2d array (column major) of a 1d array.

Example.java
int W = In.length / H;
double Out[][] = newdouble[H][W];
for (int j = 0; j < H; j++)
    for (int i = 0; i < W; i++)
        Out[i][j] = In[j * W + i];
return Out;
